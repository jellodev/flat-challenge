# 찰랑찰랑 볼록 대작전

한 방울도 흘리지 말고, 잔 위로 볼록하게.

빌드 없는 정적 사이트(`index.html`, `styles.css`, `game.js`)라서 GitHub Pages에 그대로 올리면 됩니다.

## 배포

Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `(root)`

## 설계 메모

- 조작은 "옮기기"와 "따르기"를 분리한다(모바일: 화면 끌기 + 꾹 버튼 / 데스크톱: ←→·마우스 드래그 + Space, Enter 건배). 둘을 한 동작에 묶으면 옮기려다 따라지는 억울한 실패가 생긴다.
- 조작 자체가 적이다: 병 기울기에 관성이 있고, 따르기 시작하는 각도를 넘는 순간 기울이던 속도의 제곱만큼 한 번에 쏟아진다. 손떨림이 기울기와 병 위치에 섞인다.
- 방해 요소는 물리로 작동한다: 잔 속 출렁임(감쇠가 약한 진동자)을 실제로 일으키고, 잔을 테이블 위에서 밀어 물줄기를 빗나가게 한다.
- 흘리면 1단계로 돌아간다. 모자람·평평함·시간 초과만 같은 단계에서 다시 한다.
- 공유 링크 해시는 KST 날짜 단위라 자정이 지나면 만료된다. 서버가 없으므로 서명은 위조 억제용일 뿐 보안 장치가 아니다.
- 수치는 `STAGES`에 있다. 상태를 전부 읽는 봇으로 각 단계를 깰 수 있는지 확인했다.
